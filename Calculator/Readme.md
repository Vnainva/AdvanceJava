🧮 Java Calculator

📌 Overview

A simple calculator application developed using Java as part of Advanced Java practicals. It performs basic arithmetic calculations and demonstrates Java programming concepts.

✨ Features

Addition

Subtraction

Multiplication

Division

Basic arithmetic operations

🛠️ Technologies Used

Java

JDK

VS Code / IntelliJ IDEA / Eclipse

⚙️ Prerequisites

Java Development Kit (JDK) installed

A Java-compatible IDE or terminal

🚀 How to Run

Clone or download this repository.

Open the project in your preferred IDE.

Compile the Java source file.

Run the class containing the main() method.

For a standalone Java file:

javac Calculator.java
java Calculator

Replace Calculator.java with the actual filename if different.

🎯 Learning Outcomes

Understanding Java syntax and methods

Implementing arithmetic operations

Practicing input handling and conditional statements
