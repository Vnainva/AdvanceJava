# 🔗 Java RMI (Remote Method Invocation)

## 📌 Overview

This project demonstrates Remote Method Invocation (RMI) in Java. RMI enables an object running in one Java Virtual Machine to invoke methods on an object running in another Java Virtual Machine.

## ✨ Features

- Remote method invocation
- Client-server communication
- Remote interface implementation
- Demonstration of distributed Java applications

## 🛠️ Technologies Used

- Java
- Java RMI
- JDK

## 🏗️ How RMI Works

1. **Remote Interface:** Declares the methods that can be invoked remotely.
2. **Remote Implementation:** Implements the remote methods.
3. **RMI Server:** Registers the remote object.
4. **RMI Client:** Looks up the remote object and invokes its methods.

## ⚙️ Prerequisites

- Java Development Kit (JDK)
- IDE or terminal
- All required Java source files

## 🚀 How to Run

1. Compile the project source files.
2. Start the RMI registry if your implementation requires a separately started registry.
3. Run the server application.
4. Run the client application.
5. Follow the client prompts to invoke remote methods.

The exact commands depend on the project's class names, package structure, and registry configuration.
